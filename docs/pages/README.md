# Готовые тексты страниц

HTML-заготовки для вставки в админку Shopify. Два способа подключить:

## Вариант A — через политики Shopify (рекомендуется для юридических текстов)

**Settings → Policies (Правила)**:

| Политика | Файл |
| --- | --- |
| Privacy policy | `politika-konfidencialnosti.html` |
| Terms of service | `polzovatelskoe-soglashenie.html` |
| Refund policy | раздел «Возврат и обмен» из `polzovatelskoe-soglashenie.html` |

Вставьте текст (в редакторе политики переключитесь на HTML: кнопка `<>`), сохраните.
Shopify сам создаст страницы `/policies/...`, а тема автоматически покажет ссылки
на них в футере и гамбургере (снипет `legal-links`) и стилизует их под дизайн.

## Вариант B — через обычные страницы

**Online Store → Pages → Add page**, в редакторе содержимого нажмите `<>` (Show HTML)
и вставьте текст файла:

| Страница | Handle (важно) | Файл |
| --- | --- | --- |
| Оплата и доставка | `oplata-i-dostavka` | `oplata-i-dostavka.html` |
| Политика конфиденциальности | любой | `politika-konfidencialnosti.html` |
| Пользовательское соглашение | любой | `polzovatelskoe-soglashenie.html` |

Страницу «Оплата и доставка» тема найдёт автоматически по handle
`oplata-i-dostavka` (или `delivery`) и добавит в футер/гамбургер.

## Своё меню вместо автоссылок

Если хотите управлять составом и порядком вручную: **Online Store → Navigation →
Add menu** («Инфо»), добавьте ссылки на страницы/политики, затем выберите меню в
**Тема → Настройки → Навигация → Юридическое меню**.

⚠️ Юридические тексты — шаблоны: перед публикацией проверьте у юриста и
заполните реквизиты юридического лица (помечены `[...]`).
