# Печать ценников PRIVAT → Zebra (через диалог браузера)

Находит товар в Shopify, показывает ценник и печатает его **через системный
диалог печати браузера** (`window.print()`). Zebra выбирается в диалоге как
обычный принтер — **никакого локального агента не нужно**, страница может жить
где угодно (локально, на портале, в Shopify-приложении).

Ценник (всё по центру):

```
Код товара: <SKU>
||||| штрихкод (векторный SVG, кодирует SKU) |||||
Цена: <цена> сом
```

## Запуск (локально)

```bash
cd scripts/labels
pip3 install python-barcode pillow      # один раз
./run.sh
```

Откроется **http://localhost:8765**:

1. Ввести название / SKU / штрихкод → «Найти».
2. Кликнуть по товару — справа превью ценника (увеличенное; реальный размер мелкий).
3. Поправить цену / копии / размер этикетки при желании.
4. **🖨 Печать** — открывается диалог печати браузера, выбираешь Zebra → печать.

## Вход

На портале (`print.privat.kg`) страница закрыта **входом теми же аккаунтами, что и
портал** (`/opt/privat-portal/users.json`, scrypt): страница `/login` + cookie-сессия,
без попапа Chrome. Неавторизованных редиректит на `/login?next=…` (после входа
кассир возвращается на нужный ценник). Управление пользователями — в портале.

Локально вход отключён (`PRICETAG_AUTH_OFF=1` в `run.sh`), т.к. на маке нет файла
аккаунтов портала.

## Шаблоны этикеток (вкладка «⚙ Шаблоны»)

Размер и оформление хранятся как **именованные шаблоны** (файл `templates.json`,
создаётся автоматически из `config.json`). Во вкладке «Шаблоны» можно:

- создавать/редактировать/удалять шаблоны (ширина, высота, отступ, валюта,
  что кодировать в штрихкоде, тип штрихкода, подписи строк);
- видеть **живой предпросмотр** (меняется при вводе размера);
- назначить **активный** шаблон.

**Активный шаблон** используется печатью из админки Shopify (когда в URL нет
`template`). В режиме «Печать» шаблон выбирается в выпадающем списке.

## Маршрут печати (для кнопки в админке Shopify)

Кнопка/ссылка из админки открывает `/print` с товаром — страница сама
подставляет данные из Shopify и открывает диалог печати:

| URL | что делает |
|-----|-----------|
| `/print?variant=<id>` | ценник по варианту (тянет SKU/цену из Admin API) |
| `/print?id=<productId>` | по товару (это Shopify подставляет сам); много вариантов → выбор |
| `/print?sku=ABC&price=350` | напрямую без Shopify |
| `&template=<id>` | конкретный шаблон (иначе — активный) |
| `&w=40&h=30&copies=3&auto=1` | переопределить размер/копии; `auto=1` — сразу диалог |

Пример ссылки для Admin Link расширения приложения (берёт активный шаблон):
`https://<хост>/print?auto=1` — Shopify сам добавит `&id=<productId>`.

## Настройка (`config.json`)

| поле | что это |
|------|---------|
| `label_mm` | **размер этикетки в мм** — поставь свой (можно менять и в интерфейсе) |
| `currency` | подпись валюты (`сом`) |
| `barcode_source` | что кодировать: `sku` (по умолч.) или `barcode` |
| `symbology` | `auto` (EAN-13/UPC-A/EAN-8 по числу цифр, иначе Code128) или явно |
| `code_label` / `price_label` | подписи строк |
| `dpi`, `printer_queue`, `supersample`, `threshold` | нужны только для запасной выгрузки `.zpl` |

## Настройка принтера (разово на каждом компе)

1. Zebra добавлена как системный принтер (у нас уже: очередь `Zebra_ZPL`,
   ZD230 203 dpi, USB).
2. В диалоге печати браузера: выбрать Zebra, размер бумаги = размер этикетки,
   поля = 0, масштаб = «Реальный размер» (не «Вписать в страницу»).

## Реквизиты Shopify

Секреты в `.env.local` (в `.gitignore`, в публичный репо не попадают).
Приложение «Privat API», client credentials — как в `scripts/seo/h1_suffix.py`.
Нужен скоуп `read_products`.

## Запасной вариант — нативный ZPL

Кнопка «Скачать .zpl» и `POST /api/print` (`lp -o raw -d Zebra_ZPL`) остаются:
этикетка рендерится в 1-битную картинку под 203 dpi и уходит как ZPL `^GFA`.
Пригодится, если когда-нибудь захочется печатать не через браузер, а напрямую.
