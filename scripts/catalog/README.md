# Проверка раскладки товаров по категориям

Ищет товары, которые лежат не в своей категории (силиконовая смазка в «Обычных»),
и товары, которых не хватает в категории, куда они очевидно просятся
(«Анальная пробка» вне «Анальных пробок»).

Реквизиты берутся из `~/Downloads/sync/.env` (`SHOPIFY_STORE`, `SHOPIFY_CLIENT_ID`,
`SHOPIFY_CLIENT_SECRET`) — `shop.py` сам меняет их на 24-часовой `shpat_`-токен.

## Порядок

```bash
python3 dump_catalog.py   # выгрузка каталога в catalog.json (~2 мин, 1800 товаров)
python3 contra.py         # ЖЁСТКИЕ ошибки: название прямо противоречит категории
python3 sig.py missing    # чего не хватает: название говорит про категорию, а товара там нет
python3 audit.py          # структура дерева: сироты, дубли названий, товары без коллекций
python3 fix_all.py        # показать план правок; с `apply` — применить
```

## Что где

| файл | зачем |
|---|---|
| `shop.py` | клиент Admin GraphQL, обмен client credentials на токен |
| `dump_catalog.py` | выгружает названия, описания, статусы и коллекции всех товаров |
| `rules.py` | признаки категорий: что обязано встречаться в товаре этой категории |
| `contra.py` | взаимоисключающие признаки — только настоящие ошибки, без «а мог бы ещё» |
| `sig.py` | признаки по НАЗВАНИЮ: `alien` — чужой в категории, `missing` — не положили |
| `audit.py` | структура: подкатегория мимо родителя, родитель без подкатегорий, дубли |
| `fix_all.py` | правки списком, dry-run по умолчанию |
| `tree.json` | дерево меню; `sync/menu.json` — устаревший снимок до разводки 24.07 |

## Грабли

- **Описание врёт на поиске по подстроке.** У водных смазок в описании написано
  «не содержит силикона» и «совместима с силиконовыми игрушками» — поиск слова
  «силикон» по описанию даёт кучу ложных. Ищи по названию, описание — только для
  проверки состава (`диметикон`, `на силиконовой основе`).
- **«Без вибрации» ловится шаблоном «вибрац».** Нужен `(?<!без )`.
- **«Обычные» смазки — это водные БЕЗ спецсвойств.** Съедобные, анальные и
  возбуждающие водные живут в своих категориях и в «Обычных» их быть не должно.
- **`productsCount` в Admin API лагает**, фактический состав — через `products(first:…)`.
- **Новая коллекция создаётся неопубликованной** — `collectionCreate` оставляет
  `published_at: null`, витрина отдаёт 404. У токена «Privat API» нет
  `read_publications`, поэтому `publishablePublish` недоступен; публикуется через REST:
  `PUT /admin/api/2024-10/custom_collections/{id}.json` с `{"published": true,
  "published_scope": "web"}` (хватает `write_products`).
- **`seo.title` у коллекции витрина игнорирует** — тема генерит `<title>` сама
  («… — купить в Бишкеке недорого ❤️ Секс шоп Privat»).
- `dlia-anala` («Для Анала», 111) — осколок разводки 24.07, полная копия
  `dlya-anala` («Анальные игрушки»), в меню не используется.
